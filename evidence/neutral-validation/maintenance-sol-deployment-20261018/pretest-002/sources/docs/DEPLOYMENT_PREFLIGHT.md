# Model selection and neutral deployment preflight

This is experimental construction maintenance. No hosted model, curator,
researcher, or campaign is started by the preflight. It supplies bounded neutral
deployment observations for independent review. Host refinement and the whole
continuation proof remain open.

Use `studies/v2-study-sol.json` to select exactly `gpt-6.1-sol`, or
`studies/v2-study-astra.json` to select exactly `gpt-6-astra`. Both copy every
opportunity and budget from the unchanged `studies/v2-study.json`. The historical
Astra default is retained. Unknown identifiers fail admission and worker argv
construction; there is no model substitution. High reasoning effort, transport,
authentication, endpoint, permissions, tool flags, output schema and prompts
are unchanged. Execution identity is recorded in frozen protocol, role request,
job spec and receipt metadata, without entering the research prompt. Worker
metadata records the requested model; hosted provider identity remains untested
here. The independently frozen pretrial panel is reused unchanged; this work
does not start or change a curator.

Before any approved fresh live study, run this command from the installed
candidate root in the supervisor's approved host context. Choose an unused
output path for every invocation:

```sh
export PATH=/opt/homebrew/bin:/Users/sasha/.elan/bin:/usr/bin:/bin:/usr/sbin:/sbin
export GIT_CONFIG_NOSYSTEM=1 GIT_CONFIG_GLOBAL=/dev/null
export TMPDIR="$PWD/.scratch"
/opt/homebrew/bin/python3 -m machinery.study_deployment --out .scratch/deployment-host-001 --seconds 120
```

Exit 0 requires all of these on the actual `sandbox_prefix` path:

- Wrapped echo and pinned Lean version start successfully.
- Sibling-file read and write probes demonstrate denial outside the validator
  directory. These contain only newly generated neutral text.
- The unchanged generic `ResearchSemantics` foundation and a new neutral identity
  root compile freshly; kernel replay and the actual-premise inspector succeed.
  A required identity declaration must occur in the checked dependency closure.
- A false target fails with an actual type mismatch. A missing mandatory
  dependency fails at the actual inspector. Startup failure, signal, or timeout
  cannot satisfy either negative control.
- The actual `study_completion.check` adapter freshly compiles/replays/inspects
  the neutral exact root, then refuses resolution because an independent
  correspondence audit was deliberately not supplied.

The total compiler/probe allowance is bounded by 120 seconds by default, with
5-second startup/boundary probe caps and capped captured output. Source/profile,
environment, executable hashes, argv, return codes, signals, errors, timings,
object and premise artifacts are retained and hashed in `result.json` and
`receipt.json`. Failure exits 1 and keeps the failed evidence. A reused output
path is rejected. No unwrapped retry occurs. Review the full receipt and retained
artifacts independently; the word READY alone is not certification.

Live freeze automatically performs a new neutral preflight before creating arm
seeds or a study seal. Failure leaves only diagnostic evidence and admits no
study. A successful receipt is bound into the seal and checked on verification.
Each live arm session also runs a fresh preflight before its first new role
call, including adapter calls; failure precedes role intent/call reservations.
Recorded preflight time is separate infrastructure overhead. Frozen arm role,
validation and meta-call opportunities are unchanged. Controller wall overlaps
this time and must not be added to it. Existing live authorization is still
required; the preflight cannot authorize any model call.
