# Concept-driver paired launch (20 October 2026)

This directory is a new operations record. It does not change or overwrite the
closed paired-v3 studies, proof receipts, or their failed startup evidence.
The user requested a modified research loop and explicitly selected the same
clean seed. No previous accepted theorem, research history, strategy, or private
answer enters this fresh study.

The two arms share the exact clean problem contract, pinned dependencies,
independently selected withheld obligations, model (`gpt-6.1-sol`, high effort),
30-minute role limits, 15-minute validation limits, and complete resource guards.
The baseline receives safe review feedback and ordinary proof work. Exploration
also receives the prospective concept loop. The controller runs heavy work
sequentially. Order is disclosed rather than claimed statistically independent. The historical
baseline/exploration policy guidance and exploration-only strategy installation
remain different: this compares the exploration bundle with an exploitation
control, not an isolated causal effect of the concept driver. Shared model, seed,
suite and caps control opportunities without proving causal attribution.

`launch.py plan` is read-only with respect to research: it writes an operational
plan and starts no models or Lean. `launch.py launch --review REVIEW.json` can run
only after explicit source/test review, an exact passing test record, and the
supervisor-owned live authorization for this implementation. It first runs a
fresh independent curator with size-only bounds of two holdouts and one regression,
then freezes a new study and starts the official
controller for both arms. There are no implicit retries or successor epochs.
The controller's finite allowance and 120-hour supervisor containment limit preserve the goal as
open if it is not independently resolved. `stop` uses official STOP files.

The reviewed initial allowance is four rounds in each arm, in two-round episodes.
A protected concept can force an additional review at its actual horizon boundary.
The conservative envelope therefore funds up to four reviews and five matched
comparisons per arm, plus the optional strategy continuation trial: at most
151200 reserved seconds, 46 calls and 26 meta calls, within the identical
180000-second, 64-call, 32-meta-call arm caps. These reservations are not elapsed
time or provider cost. The first episode admits
prospective concept development and later tests whether it acquires structure.
The final paired evaluations use the same preselected obligations before/after
learning, comparable resources, exact declaration use, and preserved regressions.
Verifier limits and invalid comparisons are missing evidence, never a zero gain
or a negative mathematical result. No theorem-count performance winner is inferred.
