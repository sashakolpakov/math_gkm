# Resume the existing general-goal exploration remainder

This is an operations-only continuation of the existing concept study. It does
not create a study, change machinery/Lean/contracts, supply mathematical advice,
reset the researcher, add allowances, or rerun the closed baseline. Its command
is the official exploration `run --resume`. The baseline and previous operator
status/receipts stay preserved. This continuation is not a paired comparison.

The plan binds the latest user goal verbatim, unchanged universal root, exact
study seal/protocol/state hashes, current implementation and passing acceptance
record. A separate review binds the plan, helper, tests and test result. Existing
protected authorization and resource admission are checked without editing them.
Only one launch can be consumed; failures are retained without automatic retry.

`plan` writes provenance and starts no model or proof. `status` reads operational
metadata. `launch --review REVIEW.json` starts only the reviewed official child,
with its recorded birth identity and an owned caffeinate process. `stop` writes
the new operator and existing study's official STOP markers. The supervisor has
a finite 120-hour outer wait, an 8 MiB log bound and a 1900-second STOP cleanup
allowance. A remaining uncertain process requires reconciliation; it is never
silently replaced, relabeled as stopped, or given extra research allowance.

Only the remaining frozen exploration allowance is resumed. The exact general
conjecture remains the goal, and only the unchanged completion gates can close
it. Neither this helper nor a finite continuation promises that it will be solved.
The helper tests are mocked operations tests, not mathematical evidence.
