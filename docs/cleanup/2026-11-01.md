# Source publication and cache cleanup — 1 November 2026

The Gaussian archive retains 26 exact Lean source files, all eight admitted
statements, dependency pins, validation evidence and a standalone reproducer.
Fresh compilation/kernel replay of the 26 modules and reproduction of all eight
original inspector artifacts passed before publication.

The public update adds no compiled object or cache. It removes 1,372 tracked
Python bytecode files. Six zero-byte historical `.olean.tmp` placeholders were
also removed; they contained no binary or proof data. Five optional inactive Lean-cache release archives,
totalling 1,079,086,832 bytes, were removed after source publication was verified.
Their original manifest and SHA256SUMS remain available. Source bootstrap with
pinned dependencies is the supported path; the retired recovery command now
reports that path before attempting a download.

Locally, 1,839 audited rebuildable cache files and 34 fresh reproduction objects
were removed. Proof sources, source/data checkpoints, active pinned dependencies
and required historical validation evidence were preserved. Historical public
commits remain intact; no history rewrite or force push was used.

The full Gaussian positivity conjecture remains unproved. These storage and
reproduction checks do not establish additional mathematical results.
