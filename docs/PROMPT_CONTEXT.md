# Prompt context and retained history

Own proposer and researcher prompts have a 900,000-character transport limit.
When necessary, the controller retains the complete original request as an
immutable, content-addressed file in that role's own history, limited to 8 MiB.
The inline view first omits proof/provenance details. If it remains too large,
it also replaces repeated source-file and context-source hash maps with exact
JSON pointers and value digests. Selected reuse records may refer to an
identical displayed library record. Statements, typed conditions, root and open
obligations, prospective commitments, concept predictions and substantive
feedback remain inline. No statement is shortened to fit. Source-file hashes,
source-text digests and JSON-value digests remain distinct.

The full original request still determines invocation identity and source
permissions. Completed calls require that exact request to be reused; changing
the displayed view cannot replay or refund a completed call. Mandatory-context
overflow still stops before a new call is reserved or launched. Private
comparison/reviewer requests cannot be copied into the researcher's own history
through this mechanism. This is an operator-maintained transport facility, not
an admitted mathematical result or certified machine self-change.
