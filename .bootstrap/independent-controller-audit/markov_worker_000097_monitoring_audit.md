## Natural counts and the exact numerator identity

The interpretation as actual source pattern counts is supplied separately by the existing source theory and the new adapter.

The three count arguments are computed **in `Nat` before coercion into the ring**:

```
q = 2*r − c,
t = min (c−r) (3*r−c),
u = 3*r − 2*c.
```

Every subtraction displayed here is truncated natural subtraction. Thus `q` and `u` are zero below their thresholds; the formula is not obtained by replacing them with signed ring differences. The same convention applies to every count in the correction below.

With `H_s=fullHsFA(N,c,r,q,t,u,x)`, the defined expression is

```

   + Z^4*(H4 + 96*(1−x)^8*K),
```

where `K=fourthCountCorrectionFA(x,c,r)` is exactly

| Branch, in order | Correction `K` |
| --- | --- |
| `2*r≤c` | `min(c−2*r,4*r−c)*x^5` |
| `2*r>c` and `3*r≤2*c` | `2*(2*r−c)*x^6` |
| `3*r>2*c` and `4*r≤3*c` | `2*(c−r)*x^6` |
| Otherwise | `2*(c−r)*x^6+(4*r−3*c)*x^7` |

The branch tests and subtractions are natural operations; the resulting counts are coerced into `A`. Boundary equalities follow the weak inequalities of the earlier branch.
