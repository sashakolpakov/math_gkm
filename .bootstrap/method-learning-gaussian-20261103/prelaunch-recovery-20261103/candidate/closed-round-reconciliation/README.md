# Inactive pure closed-round diagnosis

`diagnose.py` is read-only and diagnostic-only. ROOT may run the reviewed source
on actual closed-round artifacts. Agents do not inspect the private inputs. The
program prints only fixed operational key names, canonical SHA/byte length/type,
booleans and fixed candidate labels. Unknown key names are hashed. Errors expose
only the exception class. No claim text, hypothesis IDs, payload fragments,
workspace drafts, process identities or model output are printed.

The diagnostic pins relevant native source files, the full native6f
implementation and unchanged Gaussian contracta980. It authenticates the closed
readonly plan, numeric failed researcher receipt, original commitment, once-only
receipt/call registry and full original reservation. It regenerates the researcher
request only from the immutable validated plan, without calling Arm actions.
Original history/snapshot presence and round-start(C), staged(A), postfailure(B)
canonical equivalence are reported. Input hashes must remain unchanged throughout.

A concrete source-level drift is possible because policy.request converts a
portfolio map into a list, while canonical plan serialization sorts map keys.
The diagnostic tries at most the original request's portfolio order and its
inverse in memory; the inverse accounts for the program's reverse_portfolio
operation. It accepts no approximate match: the staged canonical digest must
remain unchanged and the entire regenerated request must equal the immutable
original, including program_execution.input_hash. No field is ignored, sorted
away or overwritten on disk. This proves only an exact request reconstruction,
not permission to close a round or run another model.

The known worker source publishes no explicit final cleanup-completion flag.
The diagnostic reports that absence, the optional operational-incomplete flag,
fixed cleanup-problem classifications and global cleanup-hold presence. Numeric
-9 and a last resource sample alone do not establish completed cleanup. No PID
is queried or adopted.
