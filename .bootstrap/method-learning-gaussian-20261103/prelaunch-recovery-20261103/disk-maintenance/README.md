Every actual copy must nevertheless pass its own streaming read-count, SHA256 and metadata checks; exit 0 is insufficient.

A batch acquires the shared heavy lock and all affected old controller locks without waiting. The native Lean/model resource guards stay unchanged. The maintenance primitive uses a single trusted ditto child (30 seconds maximum), a 2 GiB plus largest-file temporary-space floor, a 60-second batch work allowance, and stops at 12 GiB free by default or 8 GiB of reported file-allocation savings. The optional `--target-free-gib` accepts an integer from 12 through 32; it changes only the free-space stopping target and is retained in batch records. File-allocation savings can differ from unique APFS blocks freed when old extents are shared; measured filesystem free space remains a separate condition.

For each file it streams the original hash, copies to a fresh same-directory temporary path, verifies bytes/permissions/owner/group/mtime/compression/allocation, fsyncs the copy, rechecks the original, retains a fresh hard-link backup, and atomically replaces the path. It post-verifies and fsyncs the replacement before deleting only its own verified backup link. Journals precede significant steps. A post-check failure restores the verified original when the exact owned identities still match. Foreign divergence retains the uncertain files and requires reconciliation; there is no blind replay or automatic cleanup of interrupted records.
